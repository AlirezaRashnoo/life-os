# HomeOS

> Your personal space for everyday life.

HomeOS is an open-source personal dashboard designed to bring your daily tools into one simple, beautiful, and customizable workspace.

Instead of switching between multiple apps for weather, notes, tasks, and bookmarks, HomeOS gives you one place to organize your day.

![HomeOS Preview](./screenshots/preview.png)

---

## ✨ Features

### 🕒 Clock

A simple and clean clock widget to keep track of your time.

### 🌤 Weather

View your current weather information directly from your homepage.

### 📅 Calendar

Manage your important dates and keep your schedule visible.

### 📝 Notes

Quickly write down ideas, reminders, and important information.

### ✅ Todo

Track your daily tasks and stay focused on what matters.

### 🔗 Quick Links

Access your most-used websites and tools instantly.

### 📌 Bookmarks

Save and organize your favorite links in one place.

---

## 🎯 Why HomeOS?

Most people start their day by opening multiple applications:

- Calendar
- Todo apps
- Notes
- Weather websites
- Bookmarks

HomeOS combines these everyday tools into a single personal workspace.

Simple. Fast. Personal.

## 🚀 Getting Started

### Prerequisites

Make sure you have:

- Node.js 20+
- npm or pnpm

### Installation

Clone the repository:

```bash
git clone https://github.com/AlirezaRashnoo/home-os.git
```

Go to the project directory:

```bash
cd homeos
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open your browser:

```
http://localhost:3000
```
